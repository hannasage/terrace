# Goals for per game

Average goals a club scored per match in a season.

**Kind:** constructed. A count divided by a count.

**Formula:** `goals_for / matches_played`, rounded to two decimals.

**Inputs:** `goals_for` and `matches_played` from `mart__club_season`.

**available_from:** 1992-93.

**Limitations:** the current season is a small-sample rate that moves as more
matches are played. Read alongside goals against per game for a full picture.
