# Draws

Matches a club drew in a season.

**Kind:** observed. A draw is a factual match outcome, counted.

**Formula:** count of matches where the club and its opponent scored equally.

**Inputs:** match results from engsoccerdata and football-data, aggregated in
`mart__club_season`.

**available_from:** 1992-93.

**Limitations:** the current season's count is partial. A draw is neither good
nor bad on its own, so this metric has no better direction.
