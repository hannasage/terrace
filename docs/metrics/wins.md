# Wins

Matches a club won in a season.

**Kind:** observed. A win is a factual match outcome, counted, not computed by a
rule.

**Formula:** count of matches where the club scored more than its opponent.

**Inputs:** match results from engsoccerdata and football-data, aggregated in
`mart__club_season`.

**available_from:** 1992-93.

**Limitations:** the current season's count is partial.
