# Goals against per game

Average goals a club conceded per match in a season.

**Kind:** constructed. A count divided by a count.

**Formula:** `goals_against / matches_played`, rounded to two decimals.

**Inputs:** `goals_against` and `matches_played` from `mart__club_season`.

**available_from:** 1992-93.

**higher_is_better:** false. Fewer goals conceded per game is better.

**Limitations:** the current season is a small-sample rate.
