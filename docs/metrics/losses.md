# Losses

Matches a club lost in a season.

**Kind:** observed. A loss is a factual match outcome, counted.

**Formula:** count of matches where the club scored fewer than its opponent.

**Inputs:** match results from engsoccerdata and football-data, aggregated in
`mart__club_season`.

**available_from:** 1992-93.

**Limitations:** the current season's count is partial.
